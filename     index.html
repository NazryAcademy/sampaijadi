Cara guna SAMPAIJADI

  1. Pilih sehingga 5 gambar rujukan dan namakan projek.
  2. Tetapkan nisbah, durasi, gaya dan bahasa.
  3. Tekan “Susun storyboard”, kemudian sunting aksi, dialog dan kamera setiap panel.
  4. Eksport PNG atau salin prompt untuk Dola. Simpan projek JSON untuk sambung kemudian.

Eksport menggunakan gambar rujukan, bukan imej AI baharu. Fail projek menyertakan gambar anda. App HTML perlu dibuka dalam pelayar yang menjalankan JavaScript; pratonton fail iPhone mungkin hanya memaparkan halaman statik.
